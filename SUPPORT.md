# Soporte

AALIE es un proyecto académico de software. Las solicitudes de soporte deben ser específicas y reproducibles.

## Antes de abrir un issue

- confirma que el problema ocurre en la versión actual;
- busca issues existentes relacionados;
- distingue entre un defecto del producto, una forma de pseudocódigo no soportada y una limitación ya documentada;
- elimina secretos, claves de API y datos personales de registros o capturas de pantalla.

## Reportes de errores

Incluye:

- entrada exacta o reproducción mínima;
- resultado esperado;
- resultado obtenido;
- navegador o entorno de ejecución cuando sea relevante;
- capturas o trazas solo cuando aporten evidencia útil;
- si el problema afecta el análisis determinista, la asistencia opcional con modelos de lenguaje, exportaciones, quizzes o infraestructura.

Para defectos del análisis matemático, incluye cuando sea posible la complejidad esperada y el razonamiento o referencia utilizada como oráculo.

## Solicitudes de funcionalidades

Explica primero el problema pedagógico o de ingeniería y luego el comportamiento deseado. Las propuestas que preserven análisis determinista, explicable y contenido modular son más fáciles de evaluar.
